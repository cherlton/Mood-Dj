## 🤔 What is Mood DJ?

> **Mood DJ** uses AI to detect your current emotional state and curates the perfect playlist to match. Just describe how you feel — and let the DJ handle the rest.

---

## 🌟 Features

| Module | Description |
|---|---|
| 🧠 **AI Mood Detection** | Classifies your mood using natural language |
| 🎶 **Dynamic Playlists** | Generates music recommendations based on emotion |
| 🎨 **Animated UI** | Smooth transitions and interactive visualisations |
| 📱 **Responsive** | Works beautifully on any device |
