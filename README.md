# 🎵 Mood DJ — AI-Powered Music Mood Selector

Mood DJ is a web application that uses AI to detect or select your current mood and curates a matching music playlist experience. Just describe how you feel — and let the DJ do the rest.

---

## ✨ Features

- 🤖 AI-powered mood detection and classification
- 🎶 Dynamic playlist generation based on emotional state
- 🎨 Clean, animated UI with smooth transitions
- 📱 Responsive design for all devices
